# Blackjack — Confirmed Rules

These rules are final for v1 (confirmed in issue #8).

| Rule | Value |
|---|---|
| Decks | 6 |
| Dealer | Hits soft 17 |
| Blackjack payout | 3:2 |
| Split-hand 21 payout | 1:1 (not 3:2); loses to dealer natural blackjack |
| Split aces | One card only, no further action |
| Insurance | Not offered |
| Re-splitting | Allowed once (max 2 hands) |
| Double | Allowed on any two cards |
| Turn timeout | 30 seconds (auto-stand) |
| Starting chips | 1,000 |
| Bet limits | Min 10 / Max 500 |

To adjust, edit `BlackjackRules.cs`.
